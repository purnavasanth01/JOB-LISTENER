## Job description (verbatim)

Aurora is hiring an Embedded Software Engineering Intern for its Lidar Software team in Bozeman. The role develops and tests firmware and Python tooling for its FirstLight lidar sensor, supports hardware debugging and automated testing, and collaborates with firmware, FPGA, optics, and manufacturing engineers.. . Responsibilities. Develop and test C++ firmware features for Aurora’s FirstLight lidar sensor, running on an embedded Linux FPGA system-on-chip platform. Build and extend Python tools that analyze sensor manufacturing and calibration data and generate the reports used to accept sensors on the production line. Bring up and debug software against real sensor hardware in the lab, using the sensor’s logging, health monitoring, and debug interfaces to root-cause issues. Write automated unit and hardware-in-the-loop tests so new sensor features and tools stay reliable in continuous integration. Work with firmware, FPGA, optics, and manufacturing engineers to turn test-station and fleet observations into software fixes and diagnostics. . Skills. Currently pursuing a BS or MS in Computer Science, Computer Engineering, Electrical Engineering, Robotics, or a related field, and returning to a degree-granting program after the internship. Proficiency in Python, including scripting for automation and data analysis. Working knowledge of modern C++ from coursework or project experience. Experience developing software in a Linux environment, including the shell, a build system, and Git. Exposure to embedded Linux (Yocto) or a real-time operating system such as FreeRTOS. Familiarity with Bazel, GDB, continuous integration, and code review workflows.
