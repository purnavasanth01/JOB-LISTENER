Job Summary The Salesforce Developer Intern will support Cambridge’s Salesforce development and DevOps team across the software delivery lifecycle. Interns will contribute to platform configuration, metadata management, automated testing, integrations, and release pipeline activities in a production-grade Salesforce environment while learning from experienced developers, administrators, and release managers. Key Deliverables and Responsibilities Support product backlog priorities through Salesforce administration and configuration, including page layouts and permission sets. Develop Salesforce solutions using Apex and Lightning Web Components and support integrations involving Snowflake, Data 360, and Cambridge-developed services. Write automated unit tests, participate in code reviews and pair programming, and contribute to build and release activities. Create test plans and test cases, perform testing, document results, and report defects. Apply Cambridge software development lifecycle, configuration, coding, testing, quality gate, and CI/CD practices. Evaluate design, configuration, and coding options and explain tradeoffs with guidance from experienced engineers. Document workflows and participate in Agile team activities, including sprint planning and work with user stories. What We Are Looking For Current undergraduate student pursuing Computer Science, Computer Information Systems, Computer Engineering, Software Engineering, Management Information Systems, Mathematics, Applied Mathematics, or a related field. Understanding of object-oriented programming with experience in Java, C#, Python, or a comparable language. Understanding of relational databases and SQL, with interest in APIs, events, consumers, and data integration. Problem-solving ability, initiative, accountability, eagerness to learn, and willingness to collaborate. Interest in Salesforce, Software as a Service, software development, or solution engineering. Prior Salesforce exposure is helpful but not required.
