Clearline Real Estate is hiring a software engineering intern to build and improve its property search platform and the systems that support it. The role focuses on full-stack development, property data pipelines and quality, testing and reliability, and third-party integrations.. . Responsibilities. Website development: Build and improve our property search platform using Next.js, TypeScript, Vercel, and Supabase (Postgres). Data pipelines: Develop and maintain scrapers, scheduled jobs, and API integrations that keep rents, availability, photos, and property details current. Testing and reliability: Troubleshoot website issues, improve monitoring, and make sure new changes are thoroughly tested before going live. AI-assisted development: Use tools such as Claude Code, Cursor, and other AI coding agents to accelerate development, automate repetitive work, and tackle larger engineering tasks efficiently. .
