Deltek is hiring a Business Intelligence Intern to support report development, data validation, and quality assurance across its business intelligence landscape. The intern will build and test reports, verify data from source to dashboard, support user acceptance testing, and document findings and defects.. . Responsibilities. Build and modify reports and dashboards using Power BI (or similar BI tools), applying core SQL and data modeling concepts. Validate data accuracy through row counts, reconciliation, and spot-checking source data against report output. Write and document test cases, and compare expected versus actual results systematically. Support user acceptance testing (UAT) processes and track issues using tools like Jira or Azure DevOps. Translate business questions into data queries and clarify ambiguous requirements by asking questions rather than assuming. Document findings, defects, and testing methodology clearly for the team and stakeholders. . Skills. Currently pursuing a degree in Data, Technology, or a related field. SQL skills, including joins, aggregations, and basic query writing. Exposure to a BI tool such as Power BI or Tableau. Basic understanding of relational databases and data modeling concepts. Basic understanding of semantics and data ontology concepts. Comfortable asking clarifying questions instead of guessing, and taking a systematic, patient approach to QA work. Basic written and verbal communication skills for documenting findings and defects. Power BI preferred. Experience with data validation techniques and basic test case writing or documentation. Exposure to UAT processes and bug tracking tools (Jira, Azure DevOps, or similar); academic exposure counts. Python or R experience (pandas, basic scripting). Coursework in statistics or data analysis. Familiarity with Snowflake or another cloud data warehouse. Salesforce or other CRM data exposure. Exposure to test automation concepts.
