## Job description (verbatim)

Snaphomz is building an AI-first real estate platform, and the Full Stack Engineer Intern will help build, optimize, and scale its applications and infrastructure. The role spans frontend experiences, backend APIs and AI integrations, cloud infrastructure, data pipelines, and deployment workflows.. . Responsibilities. You will design, build, and maintain the Snaphomz web platform using Next.js, React, Node.js, and modern frontend best practices. You will develop backend services and APIs using Node.js and Python frameworks such as FastAPI and Flask, powering AI-driven workflows, integrations, and data pipelines. You will work extensively with AWS, including static hosting and global delivery using S3, CloudFront, and Route 53, and serverless application development using Lambda, API Gateway, and event-driven patterns. You will implement and manage email and notification workflows using services such as SES, and understand how these components fit together in production environments. Infrastructure will be treated as code. You will define, generate, and maintain deployment pipelines using AWS CDK, Docker containers, and YAML-based configurations. You will be responsible for understanding and improving deployment procedures, environment management, and release workflows. You will design and work with scalable data models using MongoDB, PostgreSQL, Redis, and Firebase, ensuring performance, reliability, and clean abstractions. You will integrate external APIs such as MLS, Plaid, and Realfinity to support property, financial, and transactional data flows. You will collaborate closely with AI engineers to integrate LangChain or Emergent E1 agents, TorchServe models, and RAG-based APIs into production systems. You will help implement real-time features including notifications, event tracking, and custom CRM-like functionality, and optimize performance through caching strategies and CDN layers. CI/CD is a core part of the role. You will set up, maintain, and improve pipelines using GitHub Actions, ensuring smooth deployments across platforms such as AWS, Vercel, GCP, or OCI. You will maintain clean, modular, and well-documented code, follow best practices, and participate actively in code reviews and technical discussions. You will also explore, evaluate, and implement modern AI and automation tools, including components from Google Labs and Vertex AI, where they add real product value. . Skills.
