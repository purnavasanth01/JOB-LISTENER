## Job description (verbatim)

Irradiant Technologies is hiring a Software Engineering Co-op to customize and expand its internal database for tracking products from starting material through production and validation. The role includes database and API development, lab-tool integration, production releases, and maintaining engineering practices and infrastructure.. . Responsibilities. Take the contractor built database foundation, learn its code, infrastructure and the release process. Add and change database tables, schema migrations and API routes in the database. Build and maintain data-entry forms in the web GUI. Write SQL queries and API endpoints that answer real questions, such as tracing a device back to its print job and substrate. Work with all the stakeholder teams, such as those responsible for material production, print processing and metrological verification, to learn how they record data, and turn that into tables and forms. Your goal is to make the process efficient where the tool you are developing serves the user. Connect our existing Python tools for printing, metrology and analysis to the database through the SDK. ● Build Grafana dashboards so teams can see their data without writing SQL. Contribute to our design, lithography, and metrology software when we need to track new data or build new infrastructure. Release new versions to production, and maintain the AWS infrastructure with Terraform. Implement software best practices: version control (GitHub), pull requests, code reviews, branch policies, and CI automation. Participate in PR reviews. Ensure documentation is kept current when updates and feature changes are made. . Skills. Enrolled in a BS or MS program in Computer Science, Computer Engineering, Physics, or a related field. Strong Python skills. Experience with SQL and relational databases such as PostgreSQL. Has built or used a REST API. Comfortable with GitHub workflows: branching, PR reviews, code standards. Good communication, teamwork, and organizational skills. In the third year of study or later, or in a graduate program. Experience with FastAPI, SQLAlchemy, Alembic or Pydantic. Experience with React and TypeScript. Experience with Docker and CI/CD (GitHub Actions). Experience with AWS (RDS, ECS, S3) or Terraform. Experience handling scientific or lab data (HDF5, NPZ, CSV), or working in a lab. Interest in optics, photonics or nanofabrication. . Company Overview.
