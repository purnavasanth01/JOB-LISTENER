We’re searching for an Embedded Software Engineering Intern to join the Lidar Software team in Bozeman, MT, reporting to the team’s Tech Lead Manager. Lidar Software owns all embedded development for Aurora’s FirstLight lidar: our internally developed frequency-modulated continuous-wave (FMCW) sensor that lets the Aurora Driver see and track objects farther, faster, and with greater precision than equivalent sensors on the market today. We are hiring an intern because our next-generation sensor is ramping into production, and we need to grow both the sensor firmware and the Python tooling that manufacturing, calibration, and qualification depend on. You will ship code that runs on real sensors on real hardware benches, alongside the engineers who designed them.. In this role you will . Develop and test C++ firmware features for Aurora’s FirstLight lidar sensor, running on an embedded Linux FPGA system-on-chip platform. . Build and extend Python tools that analyze sensor manufacturing and calibration data and generate the reports used to accept sensors on the production line. . Bring up and debug software against real sensor hardware in the lab, using the sensor’s logging, health monitoring, and debug interfaces to root-cause issues. . Write automated unit and hardware-in-the-loop tests so new sensor features and tools stay reliable in continuous integration. . Work with firmware, FPGA, optics, and manufacturing engineers to turn test-station and fleet observations into software fixes and diagnostics. . Required qualifications . Currently pursuing a BS or MS in Computer Science, Computer Engineering, Electrical Engineering, Robotics, or a related field, and returning to a degree-granting program after the internship. . Proficiency in Python, including scripting for automation and data analysis. . Working knowledge of modern C++ from coursework or project experience. . Experience developing software in a Linux environment, including the shell, a build system, and Git. . Demonstrated ability to debug software that interacts with hardware, through coursework, personal projects, or a prior internship in embedded systems or robotics. . Desirable qualifications . Exposure to embedded Linux (Yocto) or a real-time operating system such as FreeRTOS. . Familiarity with Bazel, GDB, continuous integration, and code review workflows. . Python data tooling such as NumPy, pandas, matplotlib, and Protocol Buffers. . Experience with FPGA system-on-chip platforms (AMD/Xilinx Zynq or Versal) or hardware interfaces such as SPI, I2C, UART, and GPIO. .
