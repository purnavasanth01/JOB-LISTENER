## Job description (verbatim)

Skyband Systems develops the M100, an avionics system that combines satellite signals from Low Earth Orbit with inertial sensing to provide a trusted position source independent of GPS. The Software Engineering Intern will build and test production software and development tools, support system qualification and flight testing, and contribute to software used on commercial aircraft.. . Responsibilities. Write, test, and ship production software for the M100 and the systems used to develop, test, and operate it. Develop embedded and real-time software for sensor processing, system health, navigation, and aircraft interfaces. Build simulators, replay tools, and data-analysis software that turn lab and flight data into engineering decisions. Expand automated unit, integration, and hardware-in-the-loop testing, including fault injection and control of real hardware. Debug problems across software, Linux, networks, electronics, test equipment, and aircraft installations. Improve build, CI, release, and observability tooling so software changes are repeatable and traceable.
