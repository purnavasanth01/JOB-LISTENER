York Space Systems is hiring a Flight Software Engineering Intern to develop and test software that supports spacecraft flight software, vehicle integration, and automated testing. Develop and test software used to support spacecraft flight software, vehicle integration, and automated testing. Write Python, C/C++, Bash, or other software that interacts with embedded systems and spacecraft hardware. Develop software and interfaces running in embedded Linux environments. Build tools that command, monitor, configure, and validate spacecraft subsystems. Participate in Software-in-the-Loop (SITL) and Hardware-in-the-Loop (HITL) development and testing. Connect software to real hardware interfaces, networks, telemetry streams, and subsystem simulators. Troubleshoot problems across software, operating systems, networks, and hardware. Debug failures using logs, telemetry, command-line tools, debuggers, and test equipment. Develop automated tests that exercise spacecraft functionality and verify expected behavior. Participate in technical design discussions and code reviews. Work with systems, software, electrical, and test engineers to turn high-level requirements into working solutions. Identify technical risks early and help develop practical solutions. Use Git, GitLab, CI/CD, and modern software-development workflows.
