## Job description (verbatim)

BBP is an industrial automation company. The Data Science Intern assists the data science team with collecting, analyzing, and interpreting data, and supports reporting and visualization to inform business decisions.. . Responsibilities. Assist in retrieving and extracting relevant data from databases using SQL queries. Support the analysis of large datasets to identify trends, patterns, and insights. Help design and develop basic SQL-based reports to meet business needs. Create ad-hoc and scheduled reports using data visualization tools such as Tableau, Power BI, or SQL Server Reporting Services. Assist in ensuring the accuracy and completeness of data in reports. Develop basic visualizations (charts, graphs, dashboards) to represent data findings clearly. Use visualization tools to help present complex data in a simple and understandable format. Collaborate with team members to enhance the visual appeal and effectiveness of reports. Participate in testing reports and visualizations to ensure data accuracy. Identify and suggest solutions for any discrepancies or errors in the reporting process. Assist in documenting SQL queries, report development processes, and visualization techniques. Create user manuals and guidelines for report interpretation. Maintain documentation for future reference and training purposes. Participate in meetings to understand user needs and provide updates on data analysis progress. Stay informed about industry trends in data science, SQL, and data visualization. Explore and suggest new tools and techniques for improving data analysis and reporting capabilities. Provide support to end-users who experience difficulties with reports or visualizations. Adhere to data security and privacy policies when handling sensitive information. Assist in implementing best practices for securing and protecting data during analysis and reporting. Help prioritize and manage multiple data analysis tasks and meet deadlines for report generation. Communicate proactively if there are challenges in meeting project timelines. Gather feedback from end-users to improve the quality of data analysis and reporting. . Skills. Currently pursuing a Bachelor's or Master's degree in Computer Science, Statistics, Applied Mathematics, Data Science, or a related field. Basic knowledge of data mining, statistical analysis, and data visualization techniques. Familiarity with SQL and statistical software packages (e.g., Python, R, SAS). Interest in using business intelligence tools and data frameworks. Strong analytical skills and attention to detail. Proficiency in Microsoft Office Suite (Excel, Word, PowerPoint). Basic knowledge of SQL for data extraction and manipulation. Strong problem-solving skills and a willingness to learn. Ability to work both independently and collaboratively in a team environment. Effective communication skills to convey complex data findings in a clear manner. Familiarity with data visualization tools (e.g., Tableau, Power BI) is a plus. . Benefits.
