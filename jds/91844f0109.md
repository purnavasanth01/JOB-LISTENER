Key Responsibilities . Agentic Solutions . Help architect and implement agentic AI workflows that use LLMs + tools to execute multi-step tasks (plan → act → observe) with minimal human intervention.. Prototype RAG (retrieval-augmented generation) or knowledge-grounded assistants for domain-specific engineering questions and workflow automation.. Benchmark agent/model behavior using structured evaluation approaches and iterate with feedback loops.. UI / UX (Actionability Layer) . Build simple, effective UIs (web apps, dashboards, internal tools) that present model/agent outputs in an engineer-friendly way (e.g., drill-down views, confidence indicators, recommended next actions).. Implement data visualizations that help users quickly interpret results and take action.. Modeling & AI . Develop and prototype physics-based and ML models to improve engineering workflows and decision-making (e.g., predictive/diagnostic models, automation accelerators).. Work with messy, real-world datasets (structured + unstructured) and build repeatable data preparation and training/evaluation workflows.. Create clear visualizations and concise technical narratives to communicate model performance, limitations, and impact. Collaboration & Delivery . Partner with engineers and data owners to scope problems, validate assumptions, and deliver end-to-end prototypes from idea to demo-ready artifacts.. Write clean documentation and present progress in reviews/demos.. . Minimum Qualifications (Required) . Education . Currently pursuing a BS/MS/PhD in Computer Science, Data Science, Electrical/Computer Engineering, Applied Math/Physics, or a related field.. Core Technical . Strong programming skills in Python (data wrangling, modeling, experimentation).. Familiarity with ML fundamentals (supervised/unsupervised learning, metrics, overfitting, validation).. Experience with ML frameworks such as PyTorch or TensorFlow.. Agentic Solutions . Coursework, projects, or hands-on experience with LLMs, RAG, and/or agentic workflows.. Understanding of how agents operate as a sequence of actions using tools and observations (planning/execution loop concepts).. UI Development . Experience building user interfaces using modern web tooling (e.g., component-based frameworks such as React, and common visualization patterns).. Ability to connect UI to APIs/services and present results clearly (tables, charts, interactive drilldowns).. Professional . Strong communication skills and the ability to translate technical work into clear, actionable updates.. . Preferred Qualifications . Familiarity with agentic frameworks such as LangGraph LangChain, or AutoGen (or similar orchestration frameworks).. Familiarity with Code Generation tools such as Claude Code to enable low-code and no-code solutions.. Familiarity with structured evaluation tools/approaches for agent quality and reliability (e.g., evaluation harnesses, regression tests for prompts/agents).. Experience with CI/CD, MLOps-style deployment practices, or building production-minded pipelines.. Domain experience in semiconductors/manufacturing data, or high-dimensional sensor/process datasets (a plus).. Knowledge of numerical methods, physics-informed modeling, multiphysics, multiscale modeling, or simulation-driven ML.. . . What You’ll Learn / Impact .
