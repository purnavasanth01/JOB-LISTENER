## Job description (verbatim)

Seagate Technology is hiring a graduate intern to support R&D data analytics, AI, and production systems for its Recording Head Technology organization. The intern will improve Linux cluster and data-pipeline monitoring, automate production workflows, and prototype AI and root-cause analysis solutions.. . Responsibilities. Modernize and improve the efficiency of Linux cluster management and data-analytics production workflows. Develop monitoring capabilities that show production data volume and flow, including how much data enters and leaves pipelines, processing status, throughput, failures, delays, and resource utilization. Analyze production workflows to identify bottlenecks, repetitive manual steps, reliability risks, and automation opportunities. Design and implement dashboards, alerts, logs, and operational metrics that improve visibility into production health and data quality. Prototype frontier AI solutions, including large language model (LLM) applications that translate natural-language questions into safe, validated SQL queries. Explore root-cause analysis (RCA) methods using causal analysis, statistical techniques, machine learning, and engineering domain knowledge. Develop maintainable software and automation in Python and Rust, with appropriate testing, documentation, and version control. Work with R&D engineers, data analysts, and infrastructure partners to define requirements, evaluate solutions, and communicate findings. Document designs, code, results, and recommendations, and present progress and insights to teammates and stakeholders. .
