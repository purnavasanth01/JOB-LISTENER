## Job description (verbatim)

Sandisk builds internal applications on its AI platform, including production AI assistants used by engineers. The intern will develop AI agents, retrieval systems, web features, integrations, and backend services, and help evaluate and ship these tools to production.. . Responsibilities. Build and improve AI agents on our LangGraph-based platform (Python) — new tools, smarter prompts, better multi-agent workflows. Work on retrieval / RAG systems: semantic + lexical search over engineering knowledge bases (vector databases, embeddings, hybrid ranking, ingestion pipelines). Ship features in our React/Next.js + TypeScript chat frontends that engineers use every day. Build MCP (Model Context Protocol) servers that give agents new capabilities by connecting internal APIs and engineering tools. Write FastAPI/Python backend services, work with PostgreSQL and Docker, and deploy through CI/CD pipelines. Evaluate and improve agent quality: tracing/observability, retrieval benchmarks, prompt iteration. Ship real code to production — reviewed, tested, and used by real engineers, in your first weeks, not your last. . Skills. Pursuing a BS/MS in Computer Science or related field (graduating Dec 2027 or later). Proficient in at least one programming language (Python, JavaScript/TypeScript, Java, Go, …) — depth in one matters more than familiarity with many. Familiarity with web development basics (REST APIs, React or similar) or backend basics (databases, HTTP services). Demonstrated use of AI coding tools in real projects. Genuine curiosity about LLMs and AI agents — you've built something with an LLM API, even a small side project. Comfort with Git and the command line; you can read unfamiliar code and figure things out. Additional languages beyond your primary one (Python and TypeScript is our sweet spot). Hands-on with LangChain / LangGraph / LlamaIndex, or any agent framework. Exposure to RAG concepts: embeddings, vector databases, chunking, reranking. Next.js, Tailwind, or modern React patterns. Docker, Linux, CI/CD (GitHub Actions), PostgreSQL. Prompt engineering instincts; experience with Claude/GPT APIs or MCP. Hands-on proficiency with AI coding agents — Claude Code, Cursor, GitHub Copilot, or similar — as a daily part of how you write software, not an occasional autocomplete. Well-versed in the agentic developer workflow: decomposing a task for an agent, writing effective prompts and context, steering multi-step agent sessions, and knowing when to intervene. Use AI to the fullest across the lifecycle — coding, debugging, test generation, code review, and documentation — while owning the output: you verify, you understand, you're accountable for every line you ship. Good judgment about AI limits: you can tell confident-but-wrong output from correct output, and you review AI-written code as critically as human-written code. . Benefits. Mentorship from engineers building agent systems in production, not demos. The full modern AI-engineering stack on your resume: agents, RAG, MCP, LLM ops, AI-native development, full-stack delivery.
