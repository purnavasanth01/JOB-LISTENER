CliquePrize is seeking a Backend Software Engineer Intern to maintain, troubleshoot, and enhance its production AutoDialer platform. The role also manages telephony, CRM, and mobile device management integrations and supports testing, documentation, and technical support.. . Responsibilities. Own and manage ongoing updates, maintenance, and improvements to dial.cliqueprize.ai. Maintain and enhance the existing Node.js and Express.js backend architecture. Troubleshoot and resolve reported application bugs and technical issues. Improve application performance, reliability, and usability for sales representatives. Develop new features and functionality as business requirements evolve. Maintain existing functionality and implement preventative solutions for known platform issues. Improve sales representative workflows, reporting, and automation capabilities. Develop and maintain Answering Machine Detection functionality for outbound sales calls. Integrate and manage AMD capabilities through the Telnyx API. Improve the detection and handling of live answers versus voicemail. Troubleshoot call-detection accuracy, timing, and related telephony issues. Optimize automated calling workflows to improve sales representative productivity. Manage the AutoDialer's integration with Telnyx.com & Google Voice. Maintain API connectivity and telephony configuration requirements. Troubleshoot outbound calling issues, call routing, and call-status reporting. Maintain proper handling of call events, webhooks, and API responses. Implement updates required by Telnyx API changes and platform requirements. Monitor and troubleshoot telephony-related issues affecting sales representatives. Maintain and enhance the API integration between dial.cliqueprize.ai and HelloLeads.io. Ensure reliable communication and data exchange between the AutoDialer and CRM. Develop and maintain functionality for retrieving sales leads and customer records. Support the transfer and synchronization of sales representative notes, call activity, and related CRM information. Troubleshoot API connectivity, authentication, and data synchronization issues. Improve the overall workflow between the AutoDialer and CRM. Assist with implementing and managing a Mobile Device Management (MDM) solution using ManageEngine (https://www.manageengine.com/). Configure and maintain mobile device monitoring for offshore sales representatives located in Africa. Track cellular data usage, identify excessive consumption, and help prevent unexpected mobile data expenses. Assist with device enrollment, configuration, monitoring, and troubleshooting. Research and implement available ManageEngine APIs and integrations to support automated mobile data usage reporting. Develop recommendations for improving mobile device management, data visibility, and operational efficiency. Maintain technical documentation for the AutoDialer, APIs, and third-party integrations. Document application updates, bug fixes, and technical changes. Participate in testing and deployment of new functionality. Monitor application performance and investigate reported technical issues. Communicate development progress, technical challenges, and recommended improvements to the development team. . Skills. Experience with JavaScript and TypeScript. Familiarity with Answering Machine Detection (AMD). Experience with Telnyx or other cloud telephony APIs. Experience integrating CRM platforms such as HelloLeads.io. Knowledge of MySQL databases.
