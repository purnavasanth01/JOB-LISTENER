Staples is hiring a Full Stack Software Engineer Intern to help build and maintain features for its Print eCommerce applications. The intern will develop and test APIs and user interfaces, collaborate with engineering and product teams, and explore AI-assisted features.. . Responsibilities. Assist in building and maintaining full-stack features for Staples Print eCommerce applications using ASP.NET Core (C#) and React with TypeScript. Develop RESTful APIs and integrate them with React-based front-end components. Write unit and integration tests using xUnit (backend) and React Testing Library / Jest (frontend). Collaborate with senior engineers, product managers, and UX designers to deliver sprint deliverables on time. Participate in code reviews, design discussions, and Agile ceremonies (stand-ups, sprint planning, retrospectives). Explore and prototype AI-assisted features using Azure OpenAI APIs or GitHub Copilot to improve developer productivity. . Skills. Currently pursuing a Master's degree in Computer Science, Software Engineering, Information Technology, or a related field. Basic hands-on experience with C# or any object-oriented language (.NET / Java / Python) through coursework or personal projects. Familiarity with HTML, CSS, and JavaScript. Understanding of REST API concepts and how front-end and back-end systems communicate. Exposure to any relational database (MS SQL Server, PostgreSQL, MySQL) and basic SQL querying. Eager to learn new frameworks and tools in a fast-paced engineering environment. Strong problem-solving skills and attention to detail.
