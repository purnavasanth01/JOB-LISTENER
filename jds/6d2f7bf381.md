## Job description (verbatim)

IT/OT Security Intern Location: Kalamazoo, Michigan Internship Summary: The IT/OT Security Intern will support the global Operational Technology (OT) Security program by helping assess cybersecurity risks, strengthen security governance, analyze security data and alerts, and develop scripts that support existing security tools and processes. The intern will work closely with the Zoetis OT Security team and site stakeholders to help protect the safety, productivity, security, and reliability of manufacturing, laboratory, and research environments. This internship provides hands-on exposure to cybersecurity within complex IT and operational technology environments. Internship Responsibilities: Participate in security discussions and analyze data to support updates to the OT security governance framework, including Minimum Security Baselines, standards, and procedures. Partner with site teams to assess cybersecurity risks associated with projects and contribute to plans for mitigating identified risks. Assist with the development of scripts, reports, and repeatable data-quality processes under the guidance of the OT Security team. Document changes and escalate automation or data issues that could impact asset records or operations. Review OT security alerts and event data using established playbooks and escalation procedures, gather relevant context, document initial observations, and escalate suspected incidents or unusual activity to the Security Operations Center (SOC) and OT Security Lead. Participate in additional cybersecurity projects aligned with individual interests and learning goals in partnership with the OT Security team. Internship Qualifications: Currently pursuing a Bachelor’s degree in Computer Science, Information Security, Information Systems, Engineering, Sciences, or a related field, or equivalent relevant experience. Knowledge of networking concepts including TCP/IP, VLANs, routing and switching, firewalls, VPNs, and common IT/OT protocols. Experience with Windows and Linux environments, Active Directory, system logs, security alerts, vulnerability concepts, and common remediation workflows. Experience with software development and tools such as GitHub, Python, and PowerShell. Exposure to ServiceNow, CrowdStrike, and OT network anomaly detection tools is preferred. Strong attention to detail with the ability to follow established procedures, analyze information, maintain accurate records, and clearly communicate findings. Willingness to learn new systems and technologies and seek guidance when appropriate. Written and spoken English is required. Spanish, Italian, and/or Portuguese language skills are a plus.
