## Job description (verbatim)

Mytra develops robotics and distributed software for material movement and storage. The Software Engineer Intern will build, own, and test middleware integrating Mytra’s orchestration system with customer systems, translating work requests and system state between them.. . Responsibilities. Build the middleware that sits between Mytra's system and a customer's, translating the work they send us, and the state we send back. Map a customer’s worksite’s workflow onto Mytra’s, and find the places where the two don’t line up. Design robust solutions to all touch points: what happens on a message we don't understand, a missed message, a request that arrives twice, or a system that goes quiet mid-exchange?. Build the test coverage that proves the integration works without needing a live customer system on the other end. . Skills. Currently pursuing a Bachelor's or Master's in computer science, software engineering, or a related field. Comfortable in at least one backend language (Go, Python, Java, C++ or similar) and willing to work in Go. You have built something that talks to something else: an API, a service, a protocol, an app. Coursework and personal projects count!. You are adept at using AI tools to work more efficiently, but are aware of where those tools have shortcomings. You validate their output rather than trusting it inherently. You are not afraid to ask questions early and often. You can own a scoped piece of work without daily pair programming. You care whether your code is correct, and you write the tests that would catch you being wrong. Experience with relational databases, particularly SQL or Postgres. Message pub/sub technologies like NATS, Kafka, MQTT, or similar. Any experience making two systems talk that were not designed for each other. Exposure to warehouse, logistics or supply chain software. An interest in algorithms, scheduling or optimization problems. Prior internship, research, lab or competition experience. . Benefits.
