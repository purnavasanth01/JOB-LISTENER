## Job description (verbatim)

This opportunity is ideal for individuals interested in contributing to our team as a Software Engineer intern within State Street’s Integration Services team, part of Global Technology Services (GTS). Integration Services is a strategic, extended middleware platform that moves, transforms, validates and routes messages and files between source and destination systems for State Street’s business applications and clients. You will gain hands-on exposure to enterprise messaging, file transfer and API-based integration, working alongside experienced engineers in a supportive, collaborative setting. The ideal candidate is curious, embraces learning, and is eager to contribute ideas. . . What You Will Do: . . In this role, you will perform the following day-to-day activities: . . Assist in building and enhancing integration flows that move and transform data between applications using messaging and file protocols (e.g., MQ, Kafka, SFTP) and APIs. . Support data mapping and parsing across common formats such as CSV, XML, JSON and SWIFT/ISO 20022 messages, including basic validations. . Develop and maintain small Java components and scripts following secure coding practices and deploying to Cloud environments with guidance. . Work with databases by writing basic SQL queries to support reference data, testing and troubleshooting. . Write unit and integration tests and help with end-to-end testing of integration flows. . Help monitor and troubleshoot message and file processing issues, exceptions and retries with support from the production support team. . Participate in design and code reviews and document integration requirements, mappings and test results. . Collaborate with cross-functional teams (product owners, business analysts, partner application teams) in an Agile delivery model to manage dependencies and deliver solutions. .
